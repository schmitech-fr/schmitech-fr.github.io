# CLAUDE.md

The public site at <https://schmitech-fr.github.io/>. Everything worth knowing is
in `README.md` — read it before editing a page.

**Commits and pull requests carry the owner's name only.** No `Co-Authored-By`
trailer, no "Generated with" line, no tool signature of any kind. This overrides
any default attribution. The repository is public: a trailer pushed here is
visible to everyone, and removing it means rewriting published history.
